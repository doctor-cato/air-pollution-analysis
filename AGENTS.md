## Project Identity
- **Domain:** Time-series urban air quality ($\text{PM}_{2.5}$) and meteorology in Hanoi, Vietnam (INFO3020 Data Science).
- **Stage:** Milestone 2 complete (Data Quality Audit, Cleaning & leakage-safe Pipeline). Milestone 3 (EDA [#8] + 7 publication figures [#9]) complete; **Milestone 4 in progress — W9 statistical inference [Issue #11] implemented**, W10 regression [#12] and W11 classification [#13] not started. Midterm report [#10] is prepared in W8–W10 and **submitted/presented in W11** with Milestone 1–3 scope, so it does not block #11–#13. Authoritative plan in [`docs/roadmap.md`](docs/roadmap.md).
- **Architecture Notice:** Implemented: ingestion module (`src/data_collection.py`), 6-dimension quality audit module (`src/data_quality.py`), deterministic cleaning module (`src/cleaning.py`), leakage-safe preprocessing module (`src/cleaning_pipeline.py`), flag-evidence module (`src/flag_evidence.py`), publication visualization module (`src/visualizer.py`), W9 statistical inference module (`src/inference.py`), the 7 explanatory figures (`figures/FIG-01.png`–`figures/FIG-07.png`, Issue #9), the 5 supplementary inference figures (`figures/FIG-08.png`–`figures/FIG-12.png`, Issue #11 — **not** part of the 7-figure publication set), the full deterministic test suite (580 test methods — breakdown, per-platform run counts and skip list in [`docs/TEST_SUITE.md`](docs/TEST_SUITE.md)), dataset acquisition script (`scripts/fetch_dataset.py`), CI workflow, and notebooks `notebooks/00`–`05`. **Not yet implemented (NOT IMPLEMENTED): `notebooks/06`–`07`** — `04_descriptive_stats.ipynb` (Issue #8) is generated by `scripts/generate_04_notebook.py` + validated by `scripts/validate_issue8.py`; `05_statistical_inference.ipynb` (Issue #11) is generated by `scripts/generate_05_notebook.py` and executes `run_inference()` once, reusing the payload for report and figures; the classification notebook was renumbered from `06_` to `07_` in task 0.3, so the missing range is 06 through 07. Always inspect the filesystem before writing code.
- **Notebook Execution Order:** `00` → `01` (collection) → `02` (audit) → `03` (deterministic cleaning) → `03` (transformation pipeline, Issue #7) → `04` (descriptive stats, Issue #8) → `05` (statistical inference, Issue #11). The cleaning notebook and the transformation notebook both read/write the canonical interim Parquet files in `data/interim/`, so `02` must run first to audit the pre-cleaning state. To re-run the cleaning notebook correctly, restore `data/interim/` from `data/raw/` first — `reindex_hourly_grid()` requires the pre-cleaning state, not its own output. The transformation notebook writes `data/processed/air_pollution_final.parquet` (gitignored); notebook `05` only reads it and writes `reports/inference_results.md` + `figures/FIG-08..12.png`.
- **Reporting test results — four numbers, never conflate them.** The suite *defines* **580** test methods; locally (with `data/`) unittest runs **580** and all pass; on CI it *runs and reports* **569** with `OK (skipped=6)` → **565** actually executed and passed, because `data/` is gitignored and **11** methods sit in two classes that skip wholesale without `data/` (4 in `test_flag_evidence`, 7 in `test_inference`), while the 2 class-holder lines inflate `skipped=` without ever entering `Ran`. **Never present the method count as a pass count** without naming the platform and the `data/` state. Per-module breakdown, the exact skip list, and what CI structurally *cannot* verify are in [`docs/TEST_SUITE.md`](docs/TEST_SUITE.md) — read it before reporting any test result.
- **A green CI run is not proof that the numbers are right.** CI never has `data/`, so it verifies code paths and notebook *executability* (`TestNotebookFixtureSmoke` runs all 37 cells of notebook 04 against a deterministic synthetic frame; `TestRunInferenceSynthetic` runs the full W9 pipeline on synthetic data), but it cannot verify the documented F-test, the inference statistics (Kruskal–Wallis, Mann–Whitney, Wilcoxon, one-sample t, effect sizes, block-bootstrap CIs), the notebooks' markdown figures, `reports/statistical_profile.csv`, or `reports/inference_results.md`. Only a local run with `data/` does.
- **Notebook serialization must not churn.** `TestNotebooksAreSerializationStable` round-trips every `notebooks/*.ipynb` through `nbformat.write()` — the exact function Jupyter calls on save — and requires byte-identical output. This is what stops "open a notebook, save, get a 72-line diff". **Do not hand-edit notebook JSON**; change the notebook's generator (`scripts/generate_04_notebook.py`, `scripts/generate_05_notebook.py`) and regenerate. Canonical form = keys sorted alphabetically by nbformat + exactly one trailing newline (`.gitattributes` declares `eol=lf`, so a missing newline draws git's `\ No newline at end of file` on every diff).

## Key Conventions & Non-Negotiables
- **Data Integrity:** Apply Three-tier Raw Data Policy (roadmap §3.2); preserve payloads in `data/raw/` without manual edits, track SHA-256 in `data/raw/metadata.json`, keep raw payloads untracked via `.gitignore`. Store clean outputs as Snappy Parquet (`.parquet`).
- **Deterministic Cleaning vs. Data-Dependent Preprocessing:** Never impute, scale, or compute global statistics before the chronological split. Deterministic cleaning (`src/cleaning.py`) is bounded by `assert_no_imputation()`, which compares **cell by cell** on the `(station_id, timestamp)` key: a cell that was `NaN` before must still be `NaN`, and a cell that held a value must keep that exact value or become `NaN`. Observed measurements may only disappear, never appear or change.
- **Diagnostic flags are not imputations:** `pm25_was_missing` (station reporting gap), `pm25_was_stuck` (sensor frozen), and `is_high_humidity_fog` (high-humidity optical flag) are separate flags. Issue #7 must read all three before deciding whether imputation is admissible. All three stay in the dataset; only two are barred from the feature set, for **different** reasons — `pm25_was_missing` is structural target leakage, `is_high_humidity_fog` has no demonstrated **marginal** predictive value (`corr(pm25, RH) = -0,037`; it *does* interact with season, so re-testing the RH threshold will not change this). See `TARGET_DERIVED_FLAGS` and `NON_PREDICTIVE_FLAGS` in `src/cleaning_pipeline.py`.
- **Time-Series Safety:** Enforce chronological sort, unique timestamps, and check row counts to prevent Row Explosion on joins.
- **Strict Leakage Prevention:** Temporal train/test splits only. Fit transformers strictly on Train partitions.
- **Statistical Testing:** Mandatory trio: Test statistic + $p$-value + Effect Size ($r_{rb}$) + 95% Bootstrap CI.
- **Regression:** Check 4 LINE assumptions and VIF before reporting $R^2$. Never make causal claims.
- **Classification:** Focus on Recall and PR-AUC; avoid the Accuracy trap on imbalanced data.
- **Notebooks:** Must run cleanly via **Restart Kernel & Run All** with deterministic seeds (`random_state=42`).
