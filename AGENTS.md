- **Stage:** Milestone 2 (Data Quality Audit & Deterministic Cleaning), entering Week 05. Authoritative plan in [`docs/roadmap.md`](docs/roadmap.md).
- **Architecture Notice:** Implemented: ingestion module (`src/data_collection.py`), 6-dimension quality audit module (`src/data_quality.py`), deterministic cleaning module (`src/cleaning.py`), leakage-safe preprocessing module (`src/cleaning_pipeline.py`), flag-evidence module (`src/flag_evidence.py`), unit tests (423 test tất định: `tests/test_data_collection.py` 57, `tests/test_data_quality.py` 44, `tests/test_cleaning.py` 114, `tests/test_cleaning_pipeline.py` 44, `tests/test_cleaning_pipeline_guards.py` 43, `tests/test_fetch_dataset.py` 9, `tests/test_flag_evidence.py` 44, `tests/test_pipeline_runtime_log.py` 40, `tests/test_verify_claims_rolling.py` 7, `tests/test_validate_issue8.py` 21), dataset acquisition script (`scripts/fetch_dataset.py`), CI workflow, and notebooks `notebooks/00`–`04`. **Not yet implemented (NOT IMPLEMENTED): `notebooks/05`–`07`** — `04_descriptive_stats.ipynb` (Issue #8) exists and is generated by `scripts/generate_04_notebook.py` + validated by `scripts/validate_issue8.py`; the classification notebook was renumbered from `06_` to `07_` in task 0.3, so the missing range is 05 through 07, not 05 through 06. Always inspect the filesystem before writing code.
- **Notebook Execution Order:** `00` → `01` (collection) → `02` (audit) → `03` (deterministic cleaning) → `03` (transformation pipeline, Issue #7). The cleaning notebook and the transformation notebook both read/write the canonical interim Parquet files in `data/interim/`, so `02` must run first to audit the pre-cleaning state. To re-run the cleaning notebook correctly, restore `data/interim/` from `data/raw/` first — `reindex_hourly_grid()` requires the pre-cleaning state, not its own output. The transformation notebook writes `data/processed/air_pollution_final.parquet` (gitignored).
- **Test count semantics — do not conflate these numbers.** The suite defines **423** test methods (`test_data_collection` 57, `test_data_quality` 44, `test_cleaning` 114, `test_cleaning_pipeline` 44, `test_cleaning_pipeline_guards` 43, `test_fetch_dataset` 9, `test_flag_evidence` 44, `test_pipeline_runtime_log` 40, `test_verify_claims_rolling` 7, `test_validate_issue8` 21). How many unittest actually **runs and reports** depends on platform *and* on whether `data/` exists:
  - Windows local, **with `data/`**: `Ran 423 tests` + `OK` → **423 passed, 0 skipped**.
  - Ubuntu CI `ubuntu-latest`, **no `data/`** (the repo does not commit it): `Ran 419 tests` + `OK (skipped=5)` → **414 passed, 5 skipped**.

  423 − 419 = 4 because `TestDocumentedReproduction.setUpClass` raises `unittest.SkipTest` when `data/interim/*.parquet` is absent — that skips the whole class, and its **4 methods are then never executed and are not counted in "Ran"**. The **5** skips it does report are:
  1. `setUpClass (tests/test_flag_evidence.py::TestDocumentedReproduction)` — no `data/interim/*.parquet`. This is the group that pins the documented `F = 16,78` / `p = 7,4·10⁻¹¹` against a real fit; run it locally with `python -m unittest tests.test_flag_evidence -v` after `scripts/fetch_dataset.py`.
  2. `TestScriptsUseTheComputation.test_progress_report_bullet_carries_the_computed_f_statistic` — same missing data.
  3. + 4. `test_windows_separators_in_payload_are_preserved_verbatim` and `test_metadata_block_and_runtime_log_disagree_on_separators` in `tests/test_pipeline_runtime_log.py`, gated by `@unittest.skipUnless(os.name == "nt")` because the separator invariant only exists on Windows.
  5. `TestNotebookExecutionOutputs.test_live_restart_kernel_and_run_all` in `tests/test_validate_issue8.py` skips when `data/processed/air_pollution_final.parquet` is absent. This is the only test that **executes notebook 04 end to end**, so a green CI run still does not prove notebook 04 runs — only a local run with `data/` does. Note that `scripts/validate_issue8.py` reports the same skip as an explicit `WARN`, not as a pass.

  So a green CI run does **not** mean the documented F-test **nor** notebook 04 execution was re-verified — CI never has the data. Only the local run with `data/` does. Never present the 423 method count as a pass count without saying which platform and which data state it refers to.

## Key Conventions & Non-Negotiables
- **Data Integrity:** Apply Three-tier Raw Data Policy (roadmap §3.2); preserve payloads in `data/raw/` without manual edits, track SHA-256 in `data/raw/metadata.json`, keep raw payloads untracked via `.gitignore`. Store clean outputs as Snappy Parquet (`.parquet`).
- **Deterministic Cleaning vs. Data-Dependent Preprocessing:** Never impute, scale, or compute global statistics before the chronological split. Deterministic cleaning (`src/cleaning.py`) is bounded by `assert_no_imputation()`, which compares **cell by cell** on the `(station_id, timestamp)` key: a cell that was `NaN` before must still be `NaN`, and a cell that held a value must keep that exact value or become `NaN`. Observed measurements may only disappear, never appear or change.
- **Diagnostic flags are not imputations:** `pm25_was_missing` (station reporting gap), `pm25_was_stuck` (sensor frozen), and `is_high_humidity_fog` (high-humidity optical flag) are separate flags. Issue #7 must read all three before deciding whether imputation is admissible. All three stay in the dataset; only two are barred from the feature set, for **different** reasons — `pm25_was_missing` is structural target leakage, `is_high_humidity_fog` has no demonstrated **marginal** predictive value (`corr(pm25, RH) = -0,037`; it *does* interact with season, so re-testing the RH threshold will not change this). See `TARGET_DERIVED_FLAGS` and `NON_PREDICTIVE_FLAGS` in `src/cleaning_pipeline.py`.
- **Time-Series Safety:** Enforce chronological sort, unique timestamps, and check row counts to prevent Row Explosion on joins.
- **Strict Leakage Prevention:** Temporal train/test splits only. Fit transformers strictly on Train partitions.
- **Statistical Testing:** Mandatory trio: Test statistic + $p$-value + Effect Size ($r_{rb}$) + 95% Bootstrap CI.
- **Regression:** Check 4 LINE assumptions and VIF before reporting $R^2$. Never make causal claims.
- **Classification:** Focus on Recall and PR-AUC; avoid the Accuracy trap on imbalanced data.
- **Notebooks:** Must run cleanly via **Restart Kernel & Run All** with deterministic seeds (`random_state=42`).
