# Issue #44 — Historical-source feasibility decision

**Decision date:** 2026-10-30  
**Decision:** **NO-GO for replacing CP0’s approved historical source or integrating an extended dataset now.**

OpenAQ S3 location 7441 is a technically accessible, provenance-preserving
candidate for a future separately approved study. It does not yet satisfy the
station/operator/instrument/change-history evidence required to declare it the
same physical series as either the mirror or VN002. This decision leaves VN001,
the legacy split, figures and W9 results unchanged.

## Verified proof of concept

`reports/issue44_openaq_poc.json` records immutable S3 request URLs, sample
SHA-256s, schema and aggregate counts. It was generated by reading public S3
objects without storing payloads in the repository.

| Location | 2022 files / PM2.5 rows | 2023 | 2024 | 2025 | Finding |
|---|---:|---:|---:|---:|---|
| `7441` | 190 / 4,560 | 249 / 5,793 | 365 / 8,703 | 99 / 2,345 | Public S3 data available. Payloads carry `location_id=7441`, `sensors_id=21632`, PM2.5, `µg/m³`, offsets `+07:00`, and coordinates approximately `21.021939, 105.818806`. |
| `2539` | 0 / 0 | 0 / 0 | 0 / 0 | 0 / 0 | No public S3 objects in this window. |
| `4946811` | 0 / 0 | 0 / 0 | 0 / 0 | 180 / not counted for this POC | Existing VN001 candidate begins in July 2025; it cannot supply 2022–2024. |

The `7441` year-prefixes are storage partitions, not a guarantee that every
record timestamp falls in that calendar year: the 2022 and 2024 prefix samples
include a next-year midnight record. Any future analysis must use parsed
timestamps, not S3 path years.

## API, license and provenance limits

- `GET https://api.openaq.org/v3/locations/7441` and `/2539` returned **HTTP 401
  Unauthorized** without an API key. The public S3 archive is usable, but v3
  metadata cannot be independently retrieved anonymously in this environment.
- The reviewed OpenAQ 7441 page identifies provider AirNow, US Public Domain,
  “Government Monitor” and an unknown governmental owner. The raw S3 payload
  identifies a stable sensor ID and coordinates in this POC, but not an
  instrument model, operator, calibration/QC history or documented change log.
- OpenAQ 2539 is a separate StateAir Hanoi record with no S3 coverage in this
  window. It must not be coalesced with 7441, VN001 or prospective VN002.

## Mirror comparison: limited diagnostic only

Two one-day comparisons were made after treating mirror `Date (LT)` as
`Asia/Ho_Chi_Minh` local time:

| Date | Joined hourly timestamps | Equal values | Unequal values | Interpretation |
|---|---:|---:|---:|---|
| 2022-01-01 | 24 | 22 | 2 | Compatibility signal only; insufficient to establish provenance. |
| 2025-01-01 | 24 | 0 | 24 | OpenAQ has `-999`; mirror has different values. It disproves any claim of byte/value identity for this sample. |

A matching subset cannot prove common origin; a mismatch does not identify its
cause. No mirror payload is approved, and the comparison must not be used to
map station identities or overwrite observations.

## Consequence and bounded remaining work

1. **Close the source search with NO-GO.** Do not use 7441 to substitute for
   CP0 until OpenAQ/AirNow supplies terms plus station, operator, instrument and
   2022–2025 change-history evidence. Do not ingest it as VN001 or VN002.
2. **VN001 missingness validation:** run the existing real-data audit locally,
   report hourly/daily completeness and contiguous missing blocks by the frozen
   chronological split, and use masking only as a derived-method experiment.
   Do not impute or alter observed PM2.5/PM10.
3. **FIG-01:** limit prose to the observed VN001 period; remove/avoid language
   about multi-year winter patterns or long-term trends. No figure needs to be
   regenerated merely because the extension is unavailable.
4. **CP4:** retain the completed negative traffic assessment; do not add a
   traffic covariate or causal interpretation.
5. **Issue #12:** may proceed independently on the frozen VN001 baseline with
   its existing chronological split, leakage guards and observational wording.
