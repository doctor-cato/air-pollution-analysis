# Issue #44 — Extended Historical Dataset Contract (`2.0.0-issue44-extended`)

This contract governs the implemented station-separated extended dataset `data/processed/air_pollution_extended_2022_2026.parquet` (`37,722` rows × `23` columns, `SHA-256: 6930557fbfc8e31dbcb062065b1903ccf27c433e9c0f062bd0dc382a9a1f9b02`) generated by `scripts/build_extended_historical_dataset.py`.

## 1. Core Architectural Rules

| Field / Rule | Implemented Contract |
|---|---|
| **Primary Key & Station Separation** | `(station_id, timestamp)` is strictly unique (`0` duplicates). `VN003_HANOI_OPENAQ_7441` (`28,678` rows, `2022-01-01 01:00+07:00` → `2025-04-09 22:00+07:00`) and `VN001_HANOI_556_NGUYEN_VAN_CU` (`9,044` rows, `2025-07-03 22:00+07:00` → `2026-07-15 17:00+07:00`) are stored as separate station cohorts and are **never** concatenated into a single-station series. Prospective `VN002_HANOI_US_EMBASSY` (third-party mirror) remains uningested (`NO-GO`). |
| **Observation Integrity** | Canonical `pm25` and `pm10` retain observed values only (`assert_no_imputation` verified cell-by-cell). Experimental short-gap linear interpolation (`max_gap_hours=2` within `(station_id, split)`) is isolated in `pm25_derived_interpolated` and `pm25_is_derived`. |
| **Provenance & Checksums** | Recorded in `reports/issue44_openaq_7441_manifest.json` (`raw_parquet_sha256: 57b6fbaa63089e57a6377fd85293355cb475f8d8bb62fb58b469ced27a4cdae8`) and `reports/issue44_extended_dataset_metadata.json` (`weather_backfill.raw_sha256: 303aacb68798667e2c838be09ad0047a6cedf292282e9ab250a7dfa88160923f`). |
| **Timezone & Grid** | `timestamp` is timezone-aware IANA `Asia/Ho_Chi_Minh` (UTC+7), hourly (`freq='h'`), reindexed independently within each station's observed operational window (no cross-year padding outside a station's active window). |
| **Spatial Weather Mapping** | Both stations map to `ERA5_HANOI_GRID_2105_10590` (`21.05448°N, 105.89848°E`) with documented great-circle distances: `1.704 km` for `VN001` and `9.026 km` for `VN003` (inter-station distance `7.324 km`). |
| **Chronological Split Policy** | Each station is partitioned chronologically (`80%` train / `20%` test) within its own `station_id` (`VN003`: `22,942` train / `5,736` test, cut at `2024-08-13 23:00+07:00`; `VN001`: `7,235` train / `1,809` test, cut at `2026-05-01 09:00+07:00`). Baseline `data/processed/air_pollution_final.parquet` remains byte-identical. |
| **Downstream Usage (Issues #8, #9, #11, #12, #13)** | Legacy baseline outputs (`figures/FIG-01.png`–`FIG-12.png`, `reports/statistical_profile.csv`, `reports/inference_results.md`) are preserved unchanged. Extended comparisons live in `figures/FIG-01-extended-historical.png` and `reports/issue44_legacy_vs_extended_comparison.md`. |

## 2. Schema Specification (23 Columns)

The extended dataset retains all **18 columns** of the baseline `air_pollution_final.parquet` schema (`timestamp`, `station_id`, `location`, `pm25`, `pm10`, `pm25_was_stuck`, `pm25_was_missing`, `is_high_humidity_fog`, `temperature`, `relative_humidity`, `wind_speed`, `wind_direction`, `precipitation`, `surface_pressure`, `hour_sin`, `hour_cos`, `month_sin`, `month_cos`) and appends **5 columns** for multi-year station-separated analysis:

| Column | Dtype | Definition & Bounds |
|---|---|---|
| `split` | `string` | Station-stratified chronological partition (`"train"` or `"test"`, `80%` / `20%` within each `station_id`). |
| `pm25_derived_interpolated` | `float64` | Experimental short-gap linear interpolation (`max_gap_hours=2` strictly inside `(station_id, split)`). Never overwrites canonical `pm25`. |
| `pm25_is_derived` | `bool` | `True` if and only if `pm25` was `NaN` and `pm25_derived_interpolated` was filled by bounded linear interpolation (`194` rows in `VN003`, `148` rows in `VN001`). |
| `winter_year` | `Int64` | Ending calendar year for Northern Vietnam winter months (`Dec` of year $Y-1$ and `Jan`–`Feb` of year $Y$ map to $Y$; `pd.NA` for `Mar`–`Nov`). Covers `2022` (partial: Jan–Feb 2022), `2023`, `2024`, `2025` on `VN003`, and `2026` on `VN001`. |
| `season` | `string` | Meteorological season in Northern Vietnam: `"Winter (Dec-Feb)"`, `"Spring (Mar-May)"`, `"Summer (Jun-Aug)"`, `"Autumn (Sep-Nov)"`. |

## 3. Adapter QC, Deduplication & Conflict Resolution Rules (`src/data_collection.py`)

1. **`OpenAQAdapter` (`location_id=7441` → `VN003_HANOI_OPENAQ_7441`):**
   - Filters geographic coordinates against `HANOI_BBOX` (`[20.50, 21.60]°N, [105.30, 106.10]°E`) prior to canonicalization.
   - Screens disguised missing values (`-999.0`: `3,188` rows) and negative readings (`-1.0`: `4` rows; `-6.0`: `1` row) to `NaN` (`3,193` total screened rows out of `21,401` raw rows), retaining `18,208` valid hourly observations (`0` stuck-sensor hours).
   - Reindexes strictly on the station's active window (`2022-01-01 01:00+07:00` → `2025-04-09 22:00+07:00`, `28,678` grid hours).
2. **`AirNowDOSAdapter` (`VN002_HANOI_US_EMBASSY`):**
   - Supports both verified AirNow CSV schemas: `Date (LST)` + `Value` and `Date (LT)` + `Raw Conc.` (never substitutes `NowCast Conc.`).
   - Enforces row-level QC via `_evaluate_row_qc()`: requires `QC Name == 'Valid'`, `Conc. Unit` in `{'ug/m3', 'µg/m3', ...}`, and `Duration` in `{'1 hr', '1h', ...}`. Non-compliant rows are set to `NaN` with explicit `qc_reason` (`qc_missing`, `qc_invalid`, `qc_suspect`, `invalid_unit`, `invalid_duration`, `sentinel_or_invalid_value`).
   - When `resolve_duplicates=True` (or when loading multiple YTD/MTD files):
     - Identical valid duplicates collapse to a single valid hourly observation (`identical_duplicate_hours`).
     - Any timestamp with disagreeing numeric values or disagreeing QC statuses across files is **never resolved by arbitrary row selection**; instead, `pm25` is set to `NaN`, `qc_name='Conflict'`, `qc_reason='conflicting_duplicate'`, and the full conflicting record set is appended to `df.attrs['qc_summary']['conflict_ledger']`.
